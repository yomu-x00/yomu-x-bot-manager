# 機能要件: タイムライン閲覧・削除 ＋ テスト投稿ボタン

---

## 1. タイムラインページ（自分の投稿一覧 ＋ 削除）

### 概要
サイドバーに **「Timeline」** ページを追加し、選択中のアカウントの投稿一覧を表示する。
各投稿に削除ボタンを設ける。

### 使用する既存 API
- `GET /api/accounts/{id}/timeline?count=50` — 投稿一覧取得（既存）
- 削除用に新規エンドポイントを追加（下記）

### 新規 API

#### DELETE /api/accounts/{id}/tweets/{tweet_id}

指定アカウントのツイートを削除（ツイート本体を Twitter 上から削除）する。

**Response 200**
```json
{ "status": "ok" }
```

**Response 404** — Account not found  
**Response 500** — twitter-cli からのエラー

### WebUI

- 投稿一覧をカード形式で表示（テキスト・投稿日時・いいね数・RT数）
- 各カードに **「削除」ボタン** → 確認ダイアログ → DELETE API 呼び出し
- 削除成功後はリストから該当カードを除去

---

## 2. テスト投稿ボタン

### 概要
アカウント設定画面または Schedule ページに **「テスト投稿」ボタン** を追加し、
任意のテキストを即時ツイートできるようにする。

### 使用する既存 API
`POST /api/accounts/{id}/tweet`（既存）

```json
{ "text": "テスト投稿です" }
```

### WebUI

- ボタン押下でテキスト入力モーダルを表示
- 「投稿する」でそのアカウントから即時投稿
- 成功時はトーストで `投稿しました（tweet_id: xxx）` を表示
- 投稿後に Timeline ページへ遷移するリンクを表示（任意）
